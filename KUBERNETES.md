# Kubernetes Deployment Guide

Complete guide for deploying the Customer Management Application to Kubernetes (OKE).

## 📋 Prerequisites

- Kubernetes cluster (OKE) access
- kubectl installed and configured
- Docker images pushed to OCI Registry
- Cluster admin permissions
